Classroom++ Changelog

What's new and improved in Classroom++

  • v1.0.1

    October 2026 Current
    • FIXWorks Immediately After Install: Installing or reinstalling Classroom++ now reloads any open Google Classroom tabs, so Classwork is enhanced right away instead of waiting for a manual refresh.
    • FIXNo Double Refresh: Entering a class's Classwork no longer reloads the page a second time. The view mounts fresh, so Classroom fetches that class's posts by itself and they load once, behind the loading bar. Revisiting a class keeps its layout and fetches nothing twice.

  • v1.0.0

    October 2026
    • NEWFirst public release: everything Classroom++ does now lives in one polished extension — a compact, scrollable Classwork layout and faster marking on the To review page.
    • NEWBulk Select on To Review: A checkbox on every assignment, a Select all option and a floating bar that marks the whole batch as reviewed in one pass. Shift-click picks a continuous range, and the same menu item Google uses is clicked for each row.
    • NEWClasswork Layout Switch: One toggle in the popup controls every Classwork change — 5-post scroll windows, loading all posts, centering the newest post, View all / View fewer and the Reverse order button. Turn it off and Classwork is untouched.
    • IMPROVEWorks in Every Class: Classwork is enhanced in any class you open, including archived classes, and a class you have already visited keeps its layout so returning to it is instant and nothing is fetched twice.
    • IMPROVESimpler Loading Indicator: The loading bar is now just a spinner and "Loading posts…" — the post counter was removed because Classroom never reveals how many posts are still hidden.
    • IMPROVESettings Apply Immediately: Changing a switch in the popup refreshes your open Classroom tabs so the new layout is live right away.
    • FIXOnly Two Tabs Are Touched: Home, Stream, Calendar, People and the To-do page keep Google's original layout and scrolling. Everything Classroom++ draws is scoped to Classwork and To review, and Google's own "View more" buttons are never restyled.
    • IMPROVELighter and More Private: The extension requests only storage plus classroom.google.com, bundles all of its code and fonts (no remote resources), and collects no data at all.

  • v0.2.2

    October 2026
    • NEWBulk Select: The "To review" page now gets a checkbox on every assignment you can mark reviewed, plus a floating action bar with "Select all" — mark a whole batch as reviewed in one pass instead of one by one.
    • NEWShift-Click Ranges: Click one checkbox, then shift-click another to select everything in between, across due-date groups. Shift-clicking a checked row clears the whole range.
    • NEWBulk Select Toggle: The extension popup has a switch for the multi-select checkboxes, so you can turn the "To review" additions off entirely if you prefer the plain page.
    • IMPROVEClasswork Layout Switch: The old "Smart Centering" switch is now "Classwork Layout" and controls every Classwork change in one place — scrollable 5-post topics, loading all posts, centering the newest post, View all / View fewer, and the Reverse order button. Turn it off and Classwork is left exactly as Google built it.
    • FIXAlways Activates on Enter: Entering a class sometimes did nothing until you reloaded, because Classroom can reveal a Classwork view by changing styles rather than by adding elements. A light background check now notices that and rescans — so topics are windowed and every post is loaded on entry, class switches included.
    • FIXHome and Other Tabs Stay Untouched: The extension now only acts on the Classwork tab and the "To review" page. It no longer wraps a class Stream's post list in a fixed-height scroll area (which cropped the layout and blocked page scrolling) and no longer restyles Google's own "View more" buttons, so Home, Stream, People, Calendar and the To-do page keep their normal layout and scrolling.

  • v0.2.1

    October 2026
    • IMPROVEFull Topic Loading: Every post in a topic is loaded up front again, so the newest published post is always found and centered — even when it sits behind several "View more" batches.
    • IMPROVENo Reload on Tab Switch: Returning to Classwork reuses the posts already loaded instead of fetching them again, and other tabs never show a loading bar.
    • FIXLoading Bar Can't Hang: The progress bar now only appears while something is actually loading and always goes away, even if Classroom keeps updating the page in the background.
    • NEWExpanding Posts Grows the Scroll Area: Opening a post to edit it grows the scroll window by the same amount, so the whole post is visible instead of being clipped.
    • FIXStable Collapse: Clicking "View fewer" keeps the button locked in place instead of jumping you near the bottom of the page.
    • IMPROVEMatching Reverse Order Button: The Reverse order button copies the "Collapse all" style and now sits directly to its left.

  • v0.2.0

    October 2026
    • NEWChalkboard Logo: Brand new icon inspired by Google Classroom with a green chalkboard, warm wood frame, and chalk "++".
    • NEWSettings Sync: Settings now automatically synchronize across all of your browsers and devices via Chrome Sync storage.
    • NEWExtension Modal & Onboarding: Full popup settings menu from the browser toolbar, welcome tour, and changelog.
    • FIXScroll Gap Elimination: Removed the trailing blank space at the bottom of topic scroll areas. Scrolling now cleanly stops flush with the final post.
    • FIXLoop Glitch Resolved: Completely resolved the infinite expanding/collapsing loop on long topics like Wednesday Write.
    • IMPROVEClean Drag-and-Drop: Removed unnecessary line feedback when dragging; drag controller isolated for smooth manual post reordering.

  • v0.1.1

    October 2026
    • IMPROVESmart Boundary Alignment: Improved alignment logic to place the latest published post in the center, next to upcoming drafts.
    • FIXHeader Menu Immunity: Protected kebab and dropdown menus from being mistaken for post lists.
    • FIXCreate Button Flash: Removed synthetic focus calls that caused the "+ Create" button to flash on page load.

  • v0.1.0

    October 2026
    • NEW5-Post Topic Window: Automatically caps topic sections to 5 visible posts with scroll and "View all" toggle.
    • NEWReverse Order: Added "Reverse order" button next to Google's "Collapse all" to sort posts in reverse.
